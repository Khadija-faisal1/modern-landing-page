# Modern Landing Page

An interactive, visually striking landing page built with HTML, CSS, and JavaScript. The experience begins with a single full-screen image where each click triggers a smooth, gooey transition that morphs into the next image. Simultaneously, the headline text slides up and swaps in sync using GSAP animations.

##  Features

* **Gooey Transitions:** Liquid-style image transitions between 5 distinct background images powered by Shery.js and Three.js.
* **Animated Headlines:** Click-to-change hero text featuring smooth, synchronized slide animations.
* **Modern Layout:** Clean navigation bar and a fully responsive hero section.
* **Smooth Performance:** Built with robust animation libraries for high-performance rendering.

##  Tech Stack

* **Frontend:** HTML5, CSS3, JavaScript
* **Animation & 3D:** GSAP (GreenSock Animation Platform), Three.js, Shery.js

##  How It Works

1. **Interact:** Click anywhere on the page to move to the next slide.
2. **Morph:** The background image shifts dynamically using a fluid, gooey effect.
3. **Swap:** The three text lines change to the next set of names and phrases.
4. **Loop:** The sequence seamlessly loops back to the start after reaching the final slide.
